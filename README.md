# JustJot(Express CRUD Application)

A clean, minimalist RESTful web application that allows users to create, read, update, and delete posts in a calming digital space.

## 🏗️ Project Architecture & Contributions

This project was built to demonstrate proficiency in backend RESTful architecture and full-stack integration. 

* **Backend & Core Architecture (My Work):** I independently designed and developed the entire backend infrastructure. This includes setting up the Node.js/Express server, designing the data blueprints, implementing full RESTful routing, managing HTTP methods (handling PATCH/DELETE via method-override), and writing the core CRUD logic.
* **Frontend & UI (AI Assisted):** To ensure a polished and professional presentation, I utilized AI to handle the frontend styling and UI/UX design, integrating Tailwind CSS via CDN for a responsive, clean, and modern card-based layout.

## 🚀 Features

* **Full CRUD Functionality:** Create, Read, Update, and Delete posts seamlessly.
* **RESTful Routing:** Adheres strictly to REST conventions for standard and predictable API endpoints.
* **Method Overriding:** Utilizes `method-override` to bypass standard HTML form limitations, allowing for native PUT/PATCH and DELETE requests.
* **Responsive Design:** A mobile-first, responsive grid layout powered by Tailwind CSS.
* **Dynamic Views:** Server-side rendering using EJS templating.

## 💻 Technologies Used

**Backend:**
* Node.js
* Express.js
* EJS (Embedded JavaScript templates)
* UUID (for unique ID generation)
* Method-Override

**Frontend:**
* HTML5
* Tailwind CSS (via CDN)
* Inter Font Family
